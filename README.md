# Infyro Farm Connect Frontend

This is the frontend application for the Infyro farm management backend.

## Stack
- React + TypeScript
- Vite
- React Router
- TanStack Query
- Axios

## Features
- Authentication flow
- Dashboard overview
- Farm management
- Field management
- Crop planting workflow
- Expense and harvest tracking
- Farm summary and reporting

## Getting started

```bash
npm install
npm run dev
```

Create a `.env` file with:

```bash
VITE_API_BASE_URL=http://localhost:8080
```
